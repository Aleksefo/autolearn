# Autolearn

Learn languages passively with this simple app.

## Tech used:
- React Native
- TypeScript
- Hooks and Context API
- Expo
- expo-speech
- expo-router
- react-native-vector-icons

This is an app that helps you learn languages passively by providing a simple interface to practice vocabulary and phrases by playing audio while you go about your day. The app uses the expo-speech library to convert text to speech, allowing you to listen to words and phrases in your target language.
